Visualizaciones Generadas
Se generaron diferentes tipos de gráficas utilizando Python, Pandas y Matplotlib para analizar las estadísticas de los partidos.

1. Gráfica de pastel
Esta grafica muestra la distribucion de resultados de los partidos, indicando el porcentaje de victorias del equipo local, victorias del visitante y empates.
Esta visualizacion permite observar qué tipo de resultado ocurre con mayor frecuencia en los partidos.

2. Boxplot de posesion
El boxplot muestra la distribucion de la posesion del balón entre los equipos locales y visitantes.
Este tipo de grafica permite identificar:

- valores promedio
- dispersion de los datos
- posibles valores atipicos

3. Scatter Plot
La grafica de dispersión compara la posesion del equipo local contra la posesión del equipo visitante.
Esto permite observar si existe una relacion entre ambas variables durante los partidos.

4. Grafica de barras
La gráfica de barras muestra el promedio de posesión del balon por equipo cuando juega como local.
Esto permite identificar qué equipos tienden a tener mayor control del balon.

5. Histogramas
Se generaron histogramas para analizar la distribucion de diferentes estadisticas del partido, como:
- posesion del equipo local
- posesion del equipo visitante
- porcentaje de tiros a puerta

Estos histogramas fueron generados automaticamente utilizando loops, lo cual permite analizar multiples variables de forma eficiente.
